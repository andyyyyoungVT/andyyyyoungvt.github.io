Privacy policy

VideoPipeline, the personal tool of the YouTube channel @andyyyyoung. Last updated 2026-10-27.

Who uses it

VideoPipeline is a private tool run on one computer by the owner of the YouTube channel @andyyyyoung, for that channel only. It is not offered to anyone else, and no other person signs in to it.

What it accesses

With the owner's permission through Google sign-in, it uses the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API to upload the channel's own videos, captions and thumbnails, read the channel's own analytics (views, watch time, retention, impressions and click-through rate), and read comments on the channel's own videos.

Where the data goes

Everything it reads is saved as notes on the owner's own computer. Nothing is sold, shared with third parties, used for advertising, or sent anywhere other than back to YouTube for the owner's own uploads. The sign-in token is stored only on that computer, and access can be removed at any time at myaccount.google.com/permissions.

Google API Services

VideoPipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Its use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.
